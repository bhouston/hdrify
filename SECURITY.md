# Security policy

## Supported versions

Security fixes target the latest stable npm release of `hdrify`, `hdrify-cli`, and `hdrify-react`. Upgrade to the latest release before checking whether an issue remains reproducible. Older releases are not maintained separately.

## Reporting a vulnerability

Email **neuralsoft@gmail.com** with a description, affected package and version, reproduction steps or a minimal sample, and the potential impact. Do not put exploitable details or sensitive files in a public issue. Coordinate disclosure with the maintainer; response timing depends on maintainer availability.
